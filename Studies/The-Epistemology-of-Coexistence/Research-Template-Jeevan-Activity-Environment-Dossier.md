# Template: *Jeevan* Activity-to-Environment Dossier

**Purpose:** Use this template once for each of the sixty-one *bal–shakti* pairs. Complete the two member records separately so that the resulting collection contains 122 activity analyses. The aim is to identify the external conditions under which each activity can operate with awakened orientation, embodied competence, public evidence, and correction, and then to test what family and institutional arrangements those conditions require.

**Methodological boundary:** The external environment does not create or switch on a constitutional activity of *jeevan*. It may support or obstruct its effective depth, right orientation, embodied expression, mutual evaluation, correction, and continuity in *sanskar*. Do not move directly from an activity name to a preferred institution. Follow the chain:

> activity → proper field → internal and embodied conditions → external affordances → recurring social function → possible institutional form

Use this template with [*The Sixty-One Activity Pairs of Jeevan*](Research-Note-Activity-Pair-Inventory.md), [*The Activity Architecture of Jeevan*](Research-Note-Bal-Shakti-And-Activity.md), [*A Functional Model of Jeevan*](Research-Note-Jeevan-Functional-Model.md), and [*From the Activity Architecture of Jeevan to Universal Human Order*](Research-Note-Jeevan-To-Universal-Human-Order.md).

## Coding conventions

### Evidential status

| Code | Meaning |
|---|---|
| **D** | Directly stated in a primary text |
| **I** | Structural inference from two or more stated claims |
| **P** | Institutional proposal consistent with the architecture but not entailed by it |
| **O** | Open question or unresolved interpretation |

### Strength of an external requirement

| Code | Meaning |
|---|---|
| **N** | Necessary field or condition: effective expression is unintelligible or impossible without it |
| **S** | Strongly supportive: not strictly necessary in every instance, but normally required for reliable continuity |
| **C** | Context-dependent: required only for some embodiments or applications |
| **U** | Unclear: the available sources or analysis do not settle the relation |
| **—** | No material relation identified |

### Institutional relation

| Code | Meaning |
|---|---|
| **P** | Primary field of development or expression |
| **E** | Enabling or protective field |
| **X** | Cross-cutting method or correctness condition |
| **?** | Candidate relation requiring further argument |
| **—** | No material relation identified |

Codes are indexing aids, not conclusions. Explain every **N**, **P**, or disputed classification in prose.
