Site APIs

Agents should start at /.well-known/api-catalog (RFC 9727) or the A2A Agent Card at /.well-known/agent-card.json. Repo skills are listed at /.well-known/agent-skills/index.json. The MCP Server Card is at /.well-known/mcp/server-card.json (SEP-1649). Web Bot Auth keys are at /.well-known/http-message-signatures-directory. In-browser agents can call catalog search, retrieval, and navigation tools through WebMCP (/webmcp.js). DNS for AI Discovery (DNS-AID) publishes ServiceMode HTTPS records at _index._agents.analyticmadhyasthdarshan.org and _a2a._agents.analyticmadhyasthdarshan.org. The catalog linkset points at the published studies catalog JSON for reading papers, and at the submission and discussion HTTP APIs for writes. Identity discovery is at /auth.md (Auth.md) plus /.well-known/oauth-protected-resource (RFC 9728).

Studies catalog

The public collection is JSON arrays the studies landing page already fetches, plus a unified file and an HTTP search that matches WebMCP search_studies. Each row has slug, title, status (ongoing, draft, or released), and, when a document exists, relative html, pdf, and md paths. Markdown is the source of truth. Resolve those paths against https://analyticmadhyasthdarshan.org/Studies/ (applied studies use ../Applications/<Slug>/).

Submission portal

Base URL: https://api.analyticmadhyasthdarshan.org. Contributors sign in with GitHub to propose studies, submit drafts, and change Draft/Released status. Reading published studies does not use this API.

A2A Agent Card

GET and HEAD /.well-known/agent-card.json return an A2A Agent Card (Content-Type: application/a2a+json). Skills cover listing and reading studies. The advertised supportedInterfaces are existing HTTP+JSON catalog URLs. This site does not run an A2A JSON-RPC runtime.

DNS for AI Discovery (DNS-AID)

Agents can discover this site from DNS before any HTTP round-trip. Query ServiceMode HTTPS records under _agents.analyticmadhyasthdarshan.org (draft-mozleywilliams-dnsop-dnsaid, RFC 9460). The zone is DNSSEC-signed. Experimental parameters use numeric keyNNNNN names until IANA registers them (key65400 is the capability URI). This site does not publish _mcp._agents under DNS-AID. Discover MCP over HTTP at /.well-known/mcp/server-card.json.

MCP

POST /mcp is Streamable HTTP JSON-RPC (read-only). Tools: search_studies, list_studies, get_study, get_study_outline, get_glossary, get_start_here, get_cite. Resources: studies://catalog-all, studies://glossary, studies://feed, studies://start-here, and studies://study/{slug} for canonical markdown. The Server Card is /.well-known/mcp/server-card.json. There are no write tools.

Agent Skills Discovery

GET and HEAD /.well-known/agent-skills/index.json return the Agent Skills Discovery index of public reader skills (start-here, cite-study, compare-traditions). Maintainer skills that need a git clone live in /.well-known/agent-skills/index-maintainer.json. Each entry is a SKILL.md with a SHA-256 digest.

Catalog document

GET and HEAD /.well-known/api-catalog return an RFC 9264 linkset (Content-Type: application/linkset+json) listing the studies catalog JSON and each write API’s service-desc, service-doc, and optional status links, following RFC 9727.
