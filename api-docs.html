Site APIs

Agents should start at /.well-known/api-catalog (RFC 9727) or the A2A Agent Card at /.well-known/agent-card.json. Repo skills are listed at /.well-known/agent-skills/index.json. The MCP Server Card is at /.well-known/mcp/server-card.json (SEP-1649). Web Bot Auth keys are at /.well-known/http-message-signatures-directory. In-browser agents can call catalog search, retrieval, and navigation tools through WebMCP (/webmcp.js). The catalog linkset points at the published studies catalog JSON for reading papers, and at the submission and discussion HTTP APIs for writes. Identity discovery is at /auth.md (Auth.md) plus /.well-known/oauth-protected-resource (RFC 9728).

Studies catalog

There is no studies REST API. The public collection is three JSON arrays the studies landing page already fetches. Each row has slug, title, status (ongoing, draft, or released), and, when a document exists, relative html and pdf paths. Resolve those paths against https://analyticmadhyasthdarshan.org/Studies/ (applied studies use ../Applications/<Slug>/).

ResourceURL
Topical studies /Studies/catalog-topical.json
Formal studies /Studies/catalog-formal.json
Applied studies /Studies/catalog-applied.json
Human catalog /Studies/index.html

Companion research notes are not catalog rows. Only curated technical notes listed in sitemap.xml are published as public pages.

Submission portal

Base URL: https://api.analyticmadhyasthdarshan.org. Contributors sign in with GitHub to propose studies, submit drafts, and change Draft/Released status. Reading published studies does not use this API.

ResourceURL
OpenAPI description /openapi/submissions.json
Health GET /api/health
Maintainer notes infra/worker/README.md

Write routes require a first-party session cookie from GitHub OAuth and a Cloudflare Turnstile token. POST /api/notify is a server-to-server hook authenticated with a shared secret, not a public client.

Discussions

Identity

Reading studies needs no account. Write APIs use human GitHub OAuth (submissions) or a verified-email magic link (discussions). This site does not issue OAuth access tokens to agents.

A2A Agent Card

GET and HEAD /.well-known/agent-card.json return an A2A Agent Card (Content-Type: application/a2a+json). Skills cover listing and reading studies. The advertised supportedInterfaces are existing HTTP+JSON catalog URLs. This site does not run an A2A JSON-RPC runtime.

Agent Skills Discovery

GET and HEAD /.well-known/agent-skills/index.json return the Agent Skills Discovery index (Content-Type: application/json, schema https://schemas.agentskills.io/discovery/0.2.0/schema.json). Each entry is a repo skill from .agents/skills/, served as SKILL.md with a SHA-256 digest.

Catalog document

GET and HEAD /.well-known/api-catalog return an RFC 9264 linkset (Content-Type: application/linkset+json) listing the studies catalog JSON and each write API’s service-desc, service-doc, and optional status links, following RFC 9727.
