Site APIs

Analytic Madhyasth Darshan publishes two HTTP APIs: the Web Submission Portal backend and the per-study discussion boards. Agents can discover them from the RFC 9727 API catalog at /.well-known/api-catalog.

Submission portal

Base URL: https://api.analyticmadhyasthdarshan.org. Contributors sign in with GitHub to propose studies, submit drafts, and change Draft/Released status. Reading published studies does not use this API.

ResourceURL
OpenAPI description /openapi/submissions.json
Health GET /api/health
Maintainer notes infra/worker/README.md

Write routes require a first-party session cookie from GitHub OAuth and a Cloudflare Turnstile token. POST /api/notify is a server-to-server hook authenticated with a shared secret, not a public client.

Discussions

Base URL: https://analyticmadhyasthdarshan.org. Readers sign in with an email magic link to comment on a study.

ResourceURL
OpenAPI description /openapi/discussions.json
Health GET /api/discussions/health
Maintainer notes infra/discussions-worker/README.md

Catalog document

GET and HEAD /.well-known/api-catalog return an RFC 9264 linkset (Content-Type: application/linkset+json) listing each API’s service-desc, service-doc, and status links, following RFC 9727.
