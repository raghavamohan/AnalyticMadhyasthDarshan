# Shared terminology for Nagraj recorded-session transcripts

English renderings used when promoting Tier-1 (and later) sessions. **Authority is only** [`MD-Mapping.xlsx`](../MD-Mapping.xlsx) and Rakesh Gupta's published MVD / SB / JV English. Do not invent glosses; search MVD *and* SB space-insensitively before flagging a term as unmapped (see the 2010 Sakshatkar session lesson).

Session-specific additions belong in that session's Conventions table, not here.
