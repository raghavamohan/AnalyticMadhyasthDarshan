# Shared visual theme

Approved asset kit: Jeevan J1 and Akhand Samaj A1 with the requested golden
nucleus. Open `preview.html` for the identity, topic icons, website and slide
examples, and working waiting animations. These are new assets; existing site
pages, deck sources, and the legacy `Assets/Icons` families are not replaced.

## Meaning and geometry

- **Jeevan:** atma at the centre, then buddhi, citta, vritti and mun from inside
  outward. All four rings remain present in the compact cut. A pictorial mark is
  not a physical measurement or a scale model.
- **Akhand Samaj:** four equal connected sections for resolution, prosperity,
  fearlessness and coexistence, with a golden nucleus as requested. In the
  explanatory version, clockwise from the upper right: resolution, prosperity,
  fearlessness, coexistence. The centre carries the atma association inherited
  from the existing family; it is not a fifth social goal, a ruler or a central
  institution. Two alternating colours distinguish adjoining sections without
  assigning a hierarchy to the goals.
- Use the two marks for identity. Topic icons describe subjects. Interface icons
  describe actions. Do not substitute the Jeevan emblem for every bullet,
  comparison tradition, eye, person, knowledge claim or status indicator.
- The original ontology deck's labelled faculty figure is teaching content.
  Preserve its labels and source reference when adopting the new visual style.

## Files

- `build-theme.cjs`: authored vector geometry, semantic map and gallery builder.
- `tokens.css`: shared colours, typography, sizing and motion rules.
- `icons/*.svg`: light, dark and monochrome exports; `*-compact.svg` for identities.
- `icons/sprite.svg`: single-colour topic/interface symbols for web use.
- `png/*.png`: transparent 512 px exports for PowerPoint and other raster consumers.
- `illustrations/`: editorial image and two labelled explanatory compositions.
- `study-visuals.json`: proposed visual assignment for every current catalog row.
- `preview.html`: standalone, responsive theme specimen with animation examples.
- `review.md`: deck-by-deck observations, website findings and adoption plan.
- `asset-guide.md`: meaning and expected use of every icon, image and export.
- `explorations/`: preserved initial six-option comparison and its SVG variants;
  historical alternatives, not the approved production identities.

Run from the repository root:

```powershell
node Assets/Theme/build-theme.cjs
node Assets/Theme/render-theme.cjs
```

The builder writes UTF-8/LF deterministically and does not touch published pages.
Raster export uses the installed repository Puppeteer/Chrome. The generated
editorial image is an authored input and is not regenerated by these scripts.

## Style contract

| Role | Rule |
| --- | --- |
| Structure | Navy `#1A5276`; ink `#2A241C` for body text |
| Emphasis | Gold `#B47B46` in large artwork; brown `#8B5E34` for small text |
| Dark field | Navy; ivory strokes and pale gold `#D5A477` accents |
| Background | Ivory `#F7F4EF`, white for dense reading surfaces |
| Topic/UI geometry | 24-unit viewBox, 1.7-unit strokes, round ends and joins |
| UI size | 20–24 px beside text; retain explicit button labels or accessible names |
| Topic size | 32–64 px; one subject symbol per card or section |
| Identity size | Full geometry at 48 px and above; compact cut below 48 px |
| Type | Cambria/Georgia headings; Calibri/Segoe UI supporting text |
| Slide hierarchy | Existing deck dimensions and type sizes remain authoritative |
| Photography/illustration | Quiet everyday learning, production and mutual participation |
| Evidence diagrams | Labels, distinctions and source notes take priority over decoration |

Do not use gold alone for small text on ivory. Colour must not be the only
identifier of a goal, tradition, status or action. Preserve labelled comparison
colours where they distinguish evidence, rather than recolouring everything blue.
Keep brand illustrations away from dense text; watermarks are for covers and
section breaks, not behind readable tables.

## Motion contract

- Jeevan waiting: subtle ring opacity changes; nucleus and geometry stay fixed.
- Akhand Samaj waiting: equal sections brighten in sequence; nucleus stays fixed.
- These motions indicate application activity only, not doctrinal faculty motion,
  spiritual progress, or a causal sequence among the four human goals.
- Use a visible task label such as “Loading studies…” or “Loading discussion…”.
  Do not show a percentage unless the application knows actual progress.
- On completion remove the waiting indicator; failures need an explicit error
  and appropriate recovery action, not an endless animation.
- `prefers-reduced-motion: reduce` disables animation and preserves the entire mark.
  The preview also has a pause control. Do not animate the nucleus, rotate the
  entire emblem, or use flashing/glowing effects.

## Adoption

The user approved this asset kit on September 11, 2026. The website integration
uses A1 for home navigation and the page title, topic icons for study cards, and
labelled waiting marks for search and discussions. The courtyard illustration
appears once in “How we work.” Secondary pages share the same home mark.

`tokens.css` owns the icon palette and motion rules. Site generators consume it
through `Scripts/_theme_icons.py`; regenerate their outputs after token changes.
Run `node Assets/Theme/render-site-icons.cjs` to rebuild the approved A1 favicon
and touch icon at the existing public URLs. These use ivory and pale gold on
navy for legibility at small sizes. Presentation adoption remains a separate
deck-pipeline change.

Verify website integration with `python Scripts/_test_theme_icons.py`,
`node Scripts/_test_theme_browser.cjs`, and
`python Scripts/_verify_studies_index.py`. The browser checks use the pinned
local Chrome and mock discussion responses, including failure and retry.
See `review.md` for exact targets and preservation requirements. Do not run the
legacy icon builders into this directory; the new marks have their own source.
